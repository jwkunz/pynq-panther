# The Pynq Panther wallpaper

`pynq-panther-wallpaper.png` (1672 x 941 pixels, 16:9) is the default desktop picture: a neon-pink line-art panther walking along a circuit
trace on black, with the *Pynq Panther* wordmark and a Python-on-a-chip logo. It was supplied by the project owner as the project's own,
original artwork (it replaces an earlier picture that used a licensed cartoon character).

* **Palette.** The theme's colours were sampled from this picture: background `#050505`; neon pink `#ff3389` (the most frequent bright
  colour: panther outline, circuit traces, chip logo); deeper trace pink `#eb196f`; soft pink `#ecacc4` for light accents.
* **Fit.** The picture has the same shape as a 1920 x 1080 screen, so it fills it exactly. On other shapes the style uses `background: aspect`
  (whole picture, proportions kept) and the picture's own near-black as the surround.
* **Your own picture.** `./install.sh --wallpaper /path/to/picture.png` (any format `feh` reads), or `--no-wallpaper` for a flat colour.
